LEX Investment Cockpit 6.2.8

Update auf Basis der vorhandenen Version 6.2.7.

Änderungen:
- Versionsanzeige auf 6.2.8 aktualisiert.
- Rendering-Funktionen gegen fehlende HTML-Elemente abgesichert.
- Watchlist-Ausgabe bricht nicht mehr ab, wenn ein Zielcontainer fehlt.
- Analyse findet eine Aktie anhand Name oder Kennung.
- Dividendenkalender berücksichtigt ausschließlich das persönliche Dividendendepot.
- Service Worker Cache auf 6.2.8 angehoben und auf Netzwerk-vorrangige Aktualisierung umgestellt.

Wichtig:
Die App ist weiterhin ein lokales Verwaltungs-Cockpit. Live-Kurse, automatische Finanzanalyse,
Push-Kursalarme und echte Quartalsbericht-Auswertung benötigen zusätzliche Datenanbieter/
Backend-Anbindungen und sind mit diesem Update nicht enthalten.
